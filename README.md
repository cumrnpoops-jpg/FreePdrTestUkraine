# FREE TEST PDR — безкоштовні тести ПДР

Безкоштовні тести ПДР України створені з метою доступу до всіх питань по темах. 
Завантажені за посиланням яке знаходиться у відкритому доступі: https://hsc.gov.ua/index/poslugi/vidacha-posvidchennya-vodiya/pitannya-ta-ispit-z-pdr/

Створено ШІ Claude

## Структура сайту (багатосторінковий)

```
/                       головна: гасло, посилання на розділи, помилки, налаштування
/exam/                  іспит (вибір категорії, «Почати іспит»)
/topics/                список усіх тем
/topics/<id>test/       тест за темою, напр. /topics/6test/ ; тема 8.1 -> /topics/8-1test/
/topics/33-<N>test/     тест за групою дорожніх знаків (33-1test — попереджувальні, 33-2test — пріоритету ...)
/tickets/               вибір категорії й номера білета та кнопка «Почати білет» на тій самій сторінці
/tickets/<N>/           білет №N (1..40)
/tickets/random/        20 випадкових питань
/mistakes/              робота над помилками
```

```
index.html, exam/, topics/, tickets/, mistakes/   згенеровані сторінки (кожна в своїй папці)
build.py           генератор усіх сторінок і sitemap.xml
css/styles.css     стилі, теми світла/темна через CSS-змінні на :root
js/data.js         питання у вигляді window.PDR_DATA
js/signs.js        групи знаків (створюється з sign-groups.json через build.py)
sign-groups.json   групи дорожніх знаків: які номери питань розділу 33 до якої групи належать
js/app.js          спільна логіка всіх сторінок (тип сторінки береться з <body data-page>)
questions.json     дані в читабельному форматі
img/               ілюстрації WebP (назва = id питання, напр. img/1-14.webp)
```

Сторінки — це звичайні статичні файли, тож сайт працює на GitHub Pages без налаштувань.
Шляхи до CSS/JS/картинок абсолютні (`/css/...`, `/img/...`), тому локально сайт треба
відкривати через сервер (наприклад `python3 -m http.server`), а не подвійним кліком по файлу.

### Зміна сторінок

HTML сторінок створює `build.py` — правте шаблони в ньому, а не окремі `index.html`:

```bash
python3 build.py
```

Скрипт читає теми з `js/data.js` і перезаписує всі сторінки та `sitemap.xml`.
Кількість білетів задає `TICKET_COUNT` на початку `build.py`.

### Перехід на головну під час тесту

Лого «PDR / FREE TEST PDR» на всіх сторінках веде на головну. Якщо тест (іспит, білет,
тема, помилки) у процесі, перед переходом з'являється діалог із підтвердженням.

`data.js` — це просто `window.PDR_DATA = <вміст questions.json>;`. Якщо правите
`questions.json`, перезберіть `data.js` однією командою:

```bash
printf 'window.PDR_DATA = ' > js/data.js && cat questions.json >> js/data.js && printf ';\n' >> js/data.js
```

Шрифти підвантажуються з Google Fonts. Якщо сайт має працювати офлайн, заберіть
`<link>` на fonts.googleapis.com з `build.py` (функція `head`) і перезапустіть його — залишиться системний шрифт.

## Зображення

Файли лежать у `img/` і названі за принципом `розділ-номер_питання.webp`,
наприклад `img/1-14.webp` — розділ 1, питання 14. Поле `src` у
`questions.json` уже посилається на потрібний файл. Формат WebP обрано заради
розміру: оригінальні PNG важили 138 МБ, після перестиснення — 16 МБ, а
завантажується в тесті лише те зображення, яке зараз на екрані (`loading="lazy"`).

Якщо для якогось питання картинки немає (або її прибрали), `<img>` тихо
ховається через `onerror` — жодної зламаної іконки на екрані.

Щоб додати чи замінити ілюстрацію, покладіть файл `img/{id_розділу}-{n}.webp`
і за потреби виставте питанню `"img": true, "src": "img/....webp"` в
`questions.json` (не забудьте перезібрати `data.js`).

## Формат даних

```json
[
  {
    "id": "1",
    "title": "Загальні положення",
    "trusted": true,
    "questions": [
      {
        "id": "1-1",
        "n": 1,
        "q": "Текст питання",
        "o": ["Варіант 1", "Варіант 2", "Варіант 3"],
        "a": 2,
        "v": true,
        "img": true,
        "src": "img/1-1.webp"
      }
    ]
  }
]
```

- `a` — індекс правильної відповіді з нуля (`2` = третій варіант). `null`, якщо
  відповіді немає; такі питання в тест не потрапляють.
- `v` — відповідь звірена з таблицею відповідей і номер не виходить за межі
  наявних варіантів.
- `img` / `src` — чи є ілюстрація та шлях до неї в `img/`.
- `trusted` — кількість питань розділу в PDF збігається з кількістю рядків
  цього розділу в таблиці відповідей (загальна ознака якості зіставлення).

## Проходження тесту

Клік по варіанту лише підсвічує вибір — сама відповідь ще не зараховується.
Внизу екрана з'являються дві кнопки: **«Обрати»** (підтверджує вибраний
варіант і показує, правильно це чи ні) та **«Пропустити»** (переходить до
наступного питання без відповіді, це питання зарахується як невідповідене).
Після підтвердження кнопка «Обрати» змінюється на «Далі» / «Завершити тест».
